# Phone field test (≈ 30 min, gloves on)

Do this on a real phone, outside, at night. Tick each box. Anything that fails: take a screenshot and note the step number.

**Before you go out (indoors, 5 min)**
- [ ] Charge to 80 %+ and unplug.
- [ ] Open the app → Settings → tap **Version** 5 times → **Field test** opens. Write down the battery % in "At start" (iPhone) or leave it (Android reads it itself). Leave it running; you'll copy the report at the end.

## 1. Install to the Home Screen
- [ ] **iPhone (Safari):** open the site → Share button (square with arrow) → **Add to Home Screen** → Add. Open it from the icon, not from Safari. It should fill the screen with no address bar.
- [ ] **Android (Chrome):** open the site → ⋮ menu → **Install app** (or "Add to Home screen"). Open it from the icon.

## 2. Push alerts
- [ ] Settings → Alerts → turn on **Push notifications** → allow. (iPhone: only works from the Home Screen icon, iOS 16.4+.)
- [ ] Tap **Send a test notification**. It arrives within ~10 s, with the phone locked.
- [ ] Tap the notification: the app opens on Tonight.

## 3. Night Vision: no white flashes
- [ ] Turn your screen brightness to minimum. Settings → **Night Vision** on.
- [ ] Open and close: Tools, a camera, the Map, the Score sheet, Settings, the keyboard (Beta feedback). **Nothing should flash white or blue.** Note any screen that does.
- [ ] Lock and unlock the phone: still red.

## 4. Glare and readability outdoors
- [ ] Night Vision off, brightness at a comfortable level: can you read the score, the verdict line and the three pills at arm's length?
- [ ] In bright light (car interior light, a street lamp): is any text too faint? Note which.

## 5. Gloves: tap targets
- [ ] With gloves on, try: the three Tonight pills, the tab bar, the Tools grid, the map timeline slider, camera stars, Settings toggles, sheet close (×).
- [ ] Count missed taps. Anything you needed 2+ tries for, note it.
- [ ] Swipe a sheet down to close it.

## 6. Offline (airplane mode)
- [ ] With signal: Tools → **Prepare for tonight** → wait until it says "Last prepared just now".
- [ ] Turn on **airplane mode**. Close and reopen the app.
- [ ] Tonight still shows a score and an "Offline · data from HH:MM" badge.
- [ ] Map still shows Iceland around you. Night plan and Learn still open.
- [ ] Log a sighting (step 8) while offline: it says it will send later.
- [ ] Turn airplane mode off: within a minute the badge goes away and the queued report is sent.

## 7. Camera links
- [ ] Cameras tab → tap three different cameras. Each opens its viewer; "Open live stream" goes to the operator's page.
- [ ] Tap **Northern Lights Cam, Churchill** → tap play. Does the video play (it starts muted)? If not, you should see a button to open it on explore.org instead.

## 8. Sighting report
- [ ] Tools → **I see aurora!** → pick brightness, colours and direction with gloves on → **Log it**.
- [ ] Map → your report appears as a glowing dot near you.
- [ ] Next morning: does "Did you see aurora last night?" appear (push or a card on Tonight)? One tap answers it.

## At the end
- [ ] Settings → tap Version 5× → type the battery % in **Now** (iPhone) → **Copy report** → paste it into the chat, plus your notes and screenshots.

| What I'll look at | Good | Needs work |
| --- | --- | --- |
| Average fps (report) | ≥ 50 | < 40 (auto Low power should have switched on) |
| Battery | ≤ 2 %-points per 10 min with the screen on | > 4 |
| Errors | 0 | any |
